# Football Goal Analyzer
**VAST Builders Challenge 2026**

AI-powered football goal analysis that tracks passing sequences and buildup play.

## 🎯 Project Goal

Build a video agent that:
- Finds all goals in football footage
- Counts passes in the buildup (10 seconds before goal)
- Analyzes play patterns (counter-attack vs buildup)
- Creates visual highlights with pass count overlays
